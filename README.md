# Sistema de Gestão de Frota

Sistema web para controle de frota, multas, pontos e formulários de defeito.

## Estrutura principal

- `index.html` — tela principal do sistema.
- `all.js` — regras e funcionalidades do front-end.
- `supabase-config.js` — configuração de conexão com o Supabase.
- `multas-iniciais.js` — dados iniciais de multas.
- `formularios_defeito_arquivos/` — arquivos PDF usados nos formulários de defeito.
- `database/schema.sql` — estrutura do banco de dados.
- `database/seed.sql` — dados importados necess´rios.
