# Arquivos grandes removidos

Esta versão é para subir no GitHub/Vercel.

Foram removidos:
- backups pesados;
- arquivos `.zip`;
- PDFs da pasta `formularios_defeito_arquivos/`.

Motivo: o GitHub reclama de arquivos/pacotes grandes no upload pelo navegador.

Se precisar manter PDFs, o ideal é guardar fora do GitHub, por exemplo:
- Supabase Storage;
- Google Drive;
- pasta local;
- ou uma pasta separada fora do deploy.

Para o sistema abrir no Vercel, estes PDFs não são obrigatórios.
