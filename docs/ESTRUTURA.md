# Estrutura do projeto

## `index.html`

Arquivo principal do sistema.

## `assets/css`

Contém os estilos que antes estavam dentro do `index.html`.

## `assets/js`

Contém os scripts que antes estavam dentro do `index.html`.

Os arquivos foram numerados para preservar a ordem de execução original.

## `supabase/sql`

Pasta reservada para guardar os scripts SQL do Supabase.

## `backup/original`

Contém uma cópia do projeto original recebido e o backup do index antes da separação.

## Atenção

Não apague os arquivos numerados de CSS/JS sem testar. Eles foram separados automaticamente a partir do index atual.
